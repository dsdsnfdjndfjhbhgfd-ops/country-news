# ev.news

Сайт: https://dsdsnfdjndfjhbhgfd-ops.github.io/country-news/ (главная о проекте), лента: `news.html#RU`

Вводишь страну и видишь главные события недели: только то, о чём пишут несколько изданий, без спорта и шоу-бизнеса.

- Новости берутся из открытой базы мировых СМИ [GDELT](https://www.gdeltproject.org/), русские и английские источники за 7 дней.
- 30 популярных стран собираются заранее GitHub Actions каждые 15 минут (три параллельных потока по 10 стран) (`scripts/prefetch.mjs` → `data/*.json`) и открываются сразу.
- Остальные страны запрашиваются у GDELT прямо из браузера (15–30 секунд), результат кэшируется в браузере на 30 минут.
- Ссылка на страну: `#KZ`, `#DE` и т. п.

## Аккаунты

Вход и регистрация через Supabase Auth (проект `ev-news`). Таблицы: `profiles` (мои страны, настройки ленты) и `saved` (сохранённые новости), доступ только к своим строкам (RLS). Код: `assets/account.js`, страница кабинета `account.html`. Лента (`news.html`) показывается только вошедшим пользователям.
