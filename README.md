# Сводка по стране

Статический сайт: вводишь страну — получаешь самые заметные публикации о ней за последние 7 дней в русских и английских СМИ.

Данные берутся прямо из браузера через открытый API [GDELT](https://www.gdeltproject.org/). Сервер и ключи не нужны.

Запуск локально: открыть `index.html` в браузере. Публикация: GitHub Pages из ветки `main`.
